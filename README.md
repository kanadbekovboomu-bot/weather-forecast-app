# ☀️ Global Weather App

Погодное приложение с поиском любого города мира и прогнозом на 5 дней без необходимости API ключа (работает на базе Open-Meteo API).

## ✨ Особенности
- 🔍 Поиск любого города мира с авто-геокодингом
- 🌡️ Текущая температура, влажность, скорость ветра и ощущение температуры
- 📅 Прогноз погоды на 5 дней вперед
- 🎨 Красивый Glassmorphism дизайн
- 🚫 Не требует платных ключей или регистрации (100% бесплатно)
